# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。

## 残渣称重闭环

- 每笔写入须同时声明投料克与残渣克；残渣不得超过炮制员设定的投料百分比，超限整笔拒写。
- 百分比由炮制员在「百分比设置」修改；质检员可看百分比与残渣履历，但不能改百分比、不能写入。
- 投料与残渣同笔写入残渣履历（快照当时百分比）；履历只追加，事后改正投料只追加一行，旧残渣不被覆盖。
- 顶栏挂「残渣门禁链」，落地页依次为百分比设置、投料残渣栏、残渣履历，总表另加投料、残渣两列数字。

### 闭环验收

1. 百分比设为 10，写投料 100、残渣 20：应失败拒写，提示超限。
2. 残渣改为 5：应成功写入，总表与履历出现该笔。
3. 总表中改正该笔投料为 600：履历追加「投料改正」行，旧称重行残渣仍为 5。
4. checker 登录：能看到百分比和履历，没有修改百分比与写入入口。
