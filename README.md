# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

残渣称重闭环：每笔写入同时声明投料克与残渣克；残渣不得超过投料的炮制员设定百分比（默认 10%），超限整笔拒写、不落地。百分比可由炮制员随时修改。投料与残渣写入只追加的残渣履历；事后改正投料只更新投料、残渣保持旧值，履历追加一行，旧残渣不被覆盖。质检员可查看百分比与履历，但不能改百分比。顶栏「残渣门禁链」为落地页，含百分比设置、投料残渣栏、残渣履历；总表在原有指标外加投料克、残渣克两列数字。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 残渣百分比设为 10：投料 100 克、残渣 20 克提交应失败（超过 10 克上限，记录不落地）；投料 100 克、残渣 5 克应成功。
5. processor 可改百分比（如改为 5），checker 打开百分比设置只见数值、无保存入口；checker 调改百分比接口返回 403。
6. 投料 100、残渣 5 写入后，在总表把该笔投料改正为 60：残渣履历出现「改正投料」行（投料 60、残渣仍记 5），原「写入」行（投料 100、残渣 5）保留不被覆盖；若改到 40（上限 4 克 < 旧残渣 5 克）则被拒写且不产生履历行。
